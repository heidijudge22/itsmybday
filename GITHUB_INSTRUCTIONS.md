# How to Push Your Birthday Party Website to GitHub

## Option 1: Using the Terminal

1. Open Terminal
2. Navigate to your project directory:
   ```
   cd ~/birthday_party_website
   ```
3. Run the push script:
   ```
   ./push_to_github.sh
   ```
4. Enter your GitHub credentials when prompted

## Option 2: Using GitHub Desktop

1. Open GitHub Desktop
2. Add Local Repository
3. Choose the folder: ~/birthday_party_website
4. Commit any changes if needed
5. Click "Publish repository" or "Push origin"

## After Pushing

1. Go to https://github.com/heidijudge22/itsmybday
2. Navigate to Settings > Pages
3. Under "Source", select "gh-pages" branch
4. Click Save
5. Your site will be published at https://heidijudge22.github.io/itsmybday

## Need Help?

If you encounter any issues, you can:
- Check GitHub's documentation: https://docs.github.com/en/get-started
- Use GitHub Desktop for a visual interface: https://desktop.github.com/
- Create a new personal access token: https://github.com/settings/tokens
