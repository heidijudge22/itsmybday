# Heidi and Dedrick's 30th Birthday Party Website

A Y2K-styled birthday party invitation website for Heidi and Dedrick's 30th birthday celebration.

## Features

- Retro Y2K-inspired design
- RSVP form with Formspree integration
- Animated confetti with custom photo stickers
- Mobile-responsive layout
- Interactive elements

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Canvas API for confetti animation

## Pages

- **Home/Invitation Page**: Contains party details and RSVP form
- **Thank You Page**: Displayed after RSVP submission
- **Confetti Test**: For testing the confetti animation

## Setup

Simply open `index.html` in a web browser to view the site. The RSVP form requires configuration with a Formspree account.
