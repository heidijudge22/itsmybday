# Using GitHub Desktop to Push Your Website

GitHub Desktop provides a user-friendly way to push your code without dealing with tokens directly in the command line.

## Steps:

1. **Download and Install GitHub Desktop**
   - Go to: https://desktop.github.com/
   - Download and install the application

2. **Sign in to GitHub**
   - Open GitHub Desktop
   - Sign in with your GitHub account

3. **Add Your Local Repository**
   - Click "Add an Existing Repository from your Hard Drive"
   - Browse to: ~/birthday_party_website
   - Click "Add Repository"

4. **Push to GitHub**
   - You should see your repository with the commits we've made
   - Click "Publish repository" (or "Push origin" if it's already published)
   - Make sure the repository name is set to "itsmybday"
   - Click "Publish Repository"

5. **Enable GitHub Pages**
   - Go to your repository on GitHub: https://github.com/heidijudge22/itsmybday
   - Go to Settings > Pages
   - Under "Source", select "gh-pages" branch
   - Click "Save"
   - Your site will be published at https://heidijudge22.github.io/itsmybday

This method handles authentication automatically through the GitHub Desktop app.
